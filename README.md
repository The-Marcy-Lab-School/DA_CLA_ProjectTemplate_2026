# CLA Capstone Exemplar Template

## Project Purpose

This repository is a template for organizing a six-week data analytics and machine learning capstone project.

It is not a completed project. Students should use this as a structure and thinking guide.

**THIS README IS NOT THE README YOU SHOULD HAVE FOR YOUR PROJECT.  THIS README IS FOR DIRECTIONS ONLY**

## Example Project Theme

Example domain: NYC traffic safety  
Example stakeholder: NYC DOT Safety Planner  
Example analytical question: What conditions are associated with higher crash injury risk?

Students should replace this with their own project.

## Repository Navigation

| Folder/File | Purpose |
|---|---|
| notebooks/ | Exploratory work, EDA, modeling process |
| src/ | Reusable functions for cleaning, features, validation, modeling |
| docs/ | Planning, AI-use log, stakeholder map, pipeline documentation |
| app/ | Deployment artifact or dashboard template |
| figures/ | Exported visuals |
| outputs/ | Model outputs, metrics tables, aggregated datasets |

## Weekly Workflow

| Week | Focus |
|---|---|
| Week 1 | Problem framing and pipeline planning |
| Week 2 | Cleaning, EDA, feature engineering |
| Week 3 | Baseline and simple model |
| Week 4 | Model tuning and optimization |
| Week 5 | Refactoring and deployment artifact |
| Week 6 | Final polish and presentation |

## Final Submission Checklist

- Clear stakeholder and analytical question
- Data source documented
- At least 5 visualizations
- At least 2 engineered features
- Baseline, simple model, and tuned models
- Leakage prevention documented
- Final model justified
- Deployment artifact included
- AI-use log completed
