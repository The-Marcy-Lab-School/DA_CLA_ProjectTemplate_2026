# Deployment Artifact Guidance

Students may choose ONE of the following:

| Option | Example |
|---|---|
| Dashboard | Tableau, Power BI, Looker Studio |
| Interactive App | Streamlit or Flask |
| Analytical Interface | Another approved free tool |

The goal is stakeholder usability.

This artifact should help stakeholders:
- understand findings
- interact with outputs
- explore trends
- view recommendations

A notebook alone does NOT count as a deployment artifact.
